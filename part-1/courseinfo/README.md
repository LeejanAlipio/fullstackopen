# Part 1
This part focuses on the core subject of the course, React.

## What I Learned

### Introduction to React
  - How to set up a react project with Vite
  - How to create and manage `Components`
  - JSX
  - How to pass and access data through `Props`

### Component State and Event Handler
  - How to works with props through destructuring 
  - How to manage state using react `useState` hook
  - How a change in the state re-renders the page
  - Handling events with event handlers
  - How event works with parent and child elements:
    - How clicking a button affects it's father element and how to stop it.
  - Practices when using `useState`:
    - If several components share the same state or they need to know the other components state to function, configure the state to the common ancestor, or the component that uses those components
